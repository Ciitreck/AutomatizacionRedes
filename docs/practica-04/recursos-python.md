# Practica 4 - Parte 2: Explorar Documentacion Oficial de Python

## 1. Respuestas Teoricas

### Que es la documentacion oficial de un lenguaje de programacion
Es como el manual de instrucciones de fabrica que hacen los mismos creadores de Python para explicar como funciona todo, es la fuente mas segura para revisar el codigo

### Que informacion puede encontrarse en ella
Se pueden encontrar tutoriales para principiantes, listas con todos los comandos, explicaciones de como instalarlo, ejemplos de codigo sencillos y avisos sobre lo nuevo que le van agregando a Python

### Como puede ayudar a resolver dudas sobre variables, listas, diccionarios, ciclos y funciones
Te enseña la forma exacta de escribir las cosas y te da trucos que ya vienen listos en Python, por ejemplo te dice que comando usar para agregar cosas a una lista o como hacer un ciclo sin equivocarte en las palabras

### Que diferencia existe entre consultar documentacion oficial y utilizar una respuesta publicada en un foro
La oficial siempre esta bien y no tiene errores porque la revisan los expertos, mientras que en un foro cualquier persona puede responder y a veces suben soluciones viejas, que no funcionan o que estan mal explicadas

## 2. Registro de Recursos de Python

### Recurso 1
* **Nombre del recurso:** El tutorial de Python
* **URL:** https://python.org
* **Tema que aborda:** Lo basico de Python, como usar ciclos, condiciones y listas
* **Tipo de información que ofrece:** Explicaciones faciles con ejemplos de codigo para copiar y probar
* **Utilidad para el proyecto integrador:** Nos sirve para revisar rapido como programar los scripts que usaremos mas adelante
* **Ejemplo de una situacion en la que lo consultaria:** Si se nos olvida como se escribe un ciclo for para revisar los equipos de red

### Recurso 2
* **Nombre del recurso:** Tipos integrados en Python
* **URL:** https://python.org
* **Tema que aborda:** Todo lo que se puede hacer con textos, listas y diccionarios
* **Tipo de informacion que ofrece:** Una lista de comandos con lo que hace cada uno
* **Utilidad para el proyecto integrador:** Nos ayuda a limpiar y acomodar los datos de los textos que nos manden los routers
* **Ejemplo de una situacion en la que lo consultaria:** Si el router nos manda un texto con espacios extra y queremos ver que comando usar para borrarlos y que quede limpio
